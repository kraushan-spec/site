## 1. Обзор продукта

### Название
**Кошелёк Онлайн** — Семейный финансовый помощник и управление договорами

### Описание
Современное веб-приложение формата PWA для комплексного управления:
- Семейными доходами и расходами
- Кредитами и долгами
- Выигранными государственными закупками и договорами
- Финансовыми целями и накоплениями

### Краткая сводка
Пользователь получает единую платформу для контроля **всех финансовых аспектов** — от повседневных расходов на продукты до крупных договоров с государством. Приложение автоматически анализирует, предупреждает, рекомендует и прогнозирует.

## 3. Проблема и решение

### Проблемы пользователей

**Проблема 1: Фрагментация данных**
- Зарплата в разных банках
- Расходы разные платёжные системы
- Кредиты в разных местах
- Тендеры на разных платформах
- **Результат:** полное отсутствие общей картины финансов

**Проблема 2: Отсутствие анализа**
- Не понимают куда уходят деньги
- Не знают сколько могут потратить
- Не видят возможностей сэкономить
- Не отслеживают прогресс к целям
- **Результат:** бесконтрольные расходы

**Проблема 3: Неуправляемые кредиты**
- Не знают оптимальную стратегию погашения
- Переплачивают на процентах
- Забывают сроки платежей
- Не видят общую кредитную нагрузку
- **Результат:** финансовые потери

**Проблема 4: Сложность контроля контрактов**
- Ручное отслеживание множества договоров
- Пропускают изменения условий
- Теряют сроки поставок
- Не видят просрочки оплат
- **Результат:** финансовые и репутационные риски

### Решение

**Кошелёк Онлайн** создаёт **единую экосистему** где:

✅ Все данные в одном месте  
✅ Автоматический анализ и рекомендации  
✅ Интеллектуальные уведомления  
✅ AI-помощник дает советы  
✅ Полный контроль за несколько кликов  
✅ Работает везде (компьютер, планшет, смартфон)  
✅ Приватность — все данные в браузере

## 4. Видение продукта

### Цель продукта
Стать личным финансовым директором каждого пользователя — помощником, который:
- **Контролирует** все денежные потоки
- **Анализирует** паттерны трат и доходов
- **Предупреждает** о рисках (красный светофор)
- **Рекомендует** действия (куда сэкономить, какой кредит погасить первым)
- **Прогнозирует** будущее (когда накопите на мечту, когда закроете кредиты)

### Стратегическое видение (1-3 года)

**Этап 1 (Текущий — v1.0):**
- Базовый функционал для личных финансов
- Управление простыми кредитами
- Базовый контроль тендеров
- Локальное хранилище

**Этап 2 (3-6 месяцев):**
- Интеграция с API Госзакупок Казахстана
- Реальный AI через Claude API
- Синхронизация между устройствами
- Web-версия с аккаунтом

**Этап 3 (6-12 месяцев):**
- Мобильное приложение (React Native/Flutter)
- Коллаборативный режим для семей
- Интеграция с банковскими API
- Machine Learning для прогнозов

**Этап 4 (1+ год):**
- Разширение на другие страны
- Интеграция с налоговыми системами
- Консультационный модуль
- B2B версия для финансовых консультантов

### 6.1 Главная страница

**Должна отвечать на 7 вопросов:**

1. **Сколько денег у меня сейчас?**
   - Текущий баланс на месяц
   - Дневной остаток

2. **Сколько денег я получу?**
   - Ожидаемые поступления
   - Регулярные доходы

3. **Сколько обязательно нужно заплатить?**
   - Коммунальные услуги
   - Кредиты
   - Налоги
   - Другие обязательные платежи

4. **Сколько я могу потратить?**
   - Свободный остаток
   - Дневной лимит
   - Недельный лимит

5. **Где я могу сэкономить?**
   - Рекомендации по категориям
   - Потенциальная экономия

6. **Какие кредиты и платежи приближаются?**
   - Календарь платежей
   - Ближайшие обязательства

7. **Какие тендеры/договоры требуют внимания?**
   - Критичные договоры
   - Требующие действия

  - Другие ключевые обязательства

### 6.8 Контроль исполнения договора

**Этапы статуса:**
1. Выигран тендер
2. Договор заключён
3. Договор действует
4. Подготовка
5. Поставка/работы
6. Акт выполнения
7. Оплата
8. Исполнен
9. Закрыт
10. Гарантийный период (если применимо)

**Требования:**
- Вручную изменяемый статус
- Автоматическое обновление (при API)
- История изменений статуса

### 6.9 Контроль изменений договора

**Критическая функция:**
- Регулярная проверка договора
- Сравнение старой и новой версии
- При обнаружении изменения:
  - 🔔 Уведомление пользователю
  - Отображение что изменилось (было → стало)
  - Дата изменения
  - Анализ влияния на срок
  - Анализ влияния на сумму
  - Анализ влияния на исполнение

**Требования:**
- История изменений не удаляется
- Все версии сохраняются
- Возможность просмотра истории

### 6.10 Контроль оплат

**Для каждого договора:**
- Сумма договора
- Получено (сумма оплачено)
- Ожидается (остаток к получению)
- Дата последней оплаты
- Дата ожидаемой оплаты

**Требования:**
- Получение от API (если доступно)
- Возможность ручного ввода
- Отслеживание просрочек
- История оплат

### 6.11 Календарь

**Визуализация:**
- Календарь месяца
- Для каждого дня показывать операции
- Цветовая кодировка:
  - 🟢 Доходы (зелёный)
  - 🔴 Обязательные платежи (красный)
  - 🟠 Кредиты (оранжевый)
  - 🔵 Расходы (синий)
  - 🟣 Тендеры/договоры (фиолетовый)
  - 🟡 Задачи (жёлтый)

**Требования:**
- Автоматический расчёт прогноза остатка на каждый день
- Быстрый просмотр операций по датам
- Переключение между месяцами

### 6.12 Прогноз

**Варианты периодов:**
- До конца текущего месяца
