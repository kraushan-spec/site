# Кошелёк Онлайн

Семейный финансовый помощник и модуль контроля выигранных тендеров/договоров — установленное PWA-приложение
для компьютера, планшета и смартфона.

## Стек

- **Next.js 16** (App Router, TypeScript, React 19)
- **Prisma + SQLite** — реальная база данных, данные сохраняются между сессиями
- **NextAuth v5** — регистрация/вход по email+паролю, сессии на JWT
- **Tailwind CSS 4**, **recharts**, **lucide-react**
- **exceljs** — экспорт в Excel (13 листов при полной выгрузке)
- **pdf-parse / mammoth** — извлечение текста из PDF/DOCX для AI-анализа договоров
- PWA: `manifest.webmanifest`, service worker (`public/sw.js`), офлайн-страница, установка на экран
- **web-push** — Web Push уведомления (опционально, требует VAPID-ключей)

## Быстрый старт

```bash
npm install
cp .env.example .env      # заполните AUTH_SECRET и TOKEN_ENCRYPTION_KEY
npx prisma migrate dev    # создаёт SQLite базу prisma/dev.db
npm run db:seed           # (опционально) демо-аккаунт demo@koshelek.online / demo12345
npm run dev
```

Откройте http://localhost:3000, зарегистрируйтесь или войдите под демо-аккаунтом.

## Переменные окружения (.env)

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DATABASE_URL` | да | путь к SQLite базе |
| `AUTH_SECRET` | да | секрет для подписи сессий NextAuth |
| `AUTH_TRUST_HOST` | при self-hosting за прокси | обязателен, если приложение работает не на стандартном хосте/порту |
| `TOKEN_ENCRYPTION_KEY` | да | ключ шифрования API-токена Госзакупок (AES-256-GCM) |
| `ANTHROPIC_API_KEY` | нет | включает LLM-анализ договоров и «умного» AI-помощника; без ключа работает детерминированный (rule-based) анализ |
| `GOSZAKUPKI_API_BASE`, `GOSZAKUPKI_API_TOKEN` | нет | серверная интеграция с порталом госзакупок (альтернатива — ввод токена в Настройках) |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | нет | включает Web Push (браузерные уведомления); без них уведомления остаются только внутри приложения |

## Архитектура модулей

- `src/lib/finance.ts` — расчёты баланса, прогноза, безопасного лимита трат, светофора, сравнения стратегий
  погашения кредитов (аваланш/снежный ком)
- `src/lib/contracts.ts`, `src/lib/contract-mutations.ts` — прогресс срока договора, оценка риска, неизменяемая
  история изменений (`ContractChange`)
- `src/lib/contract-ai.ts` — извлечение текста из документов + эвристический/LLM-анализ условий договора
- `src/lib/goszakupki.ts` — адаптер официального API госзакупок (реальный HTTP-вызов при наличии токена;
  честно сообщает о неготовности интеграции, если токен не настроен — ручной ввод договора работает всегда)
- `src/lib/ai-assistant.ts` — AI-чат, отвечающий строго на основе данных приложения
- `src/lib/excel-export.ts`, `src/app/api/export` — генерация книг Excel
- `prisma/schema.prisma` — полная модель данных (доходы/расходы, кредиты, договоры, оплаты, акты, документы,
  история изменений, комментарии, задачи, уведомления, интеграции)

## Известные ограничения

- Официальная интеграция с порталом госзакупок РК требует токена, выданного самому поставщику — код-адаптер
  выполняет реальные запросы, но требует, чтобы владелец аккаунта подключил свои учётные данные в Настройках.
- Push-уведомления браузера (Web Push) подключаются в Настройках → Уведомления после того, как на сервере заданы
  `VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` (`npx web-push generate-vapid-keys`); без ключей уведомления по-прежнему
  собираются в разделе «Задачи» и колокольчике в шапке. Push отправляется при создании уведомления — то есть при
  ближайшем открытии приложения кем-то из семьи, а не по отдельному фоновому расписанию (в проекте нет cron).
- AI-чат и AI-чтение договоров используют детерминированный анализ по умолчанию; при добавлении
  `ANTHROPIC_API_KEY` автоматически переключаются на LLM.
